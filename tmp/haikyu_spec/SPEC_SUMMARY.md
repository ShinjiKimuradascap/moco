# ハイキュー!! TOUCH THE DREAM Clone Spec

## 1. Overview
Haikyuu-like volleyball simulation RPG.

## 2. Core Loop
- Assemble team
- Match (Auto + Skill card)
- Train players

## 3. Battle System
- State-based match flow (Serve -> Receive -> Toss -> Attack/Block).
- Success rate calculation based on stats and skills.

## 4. Master Data
- Character stats, Skill multipliers.
