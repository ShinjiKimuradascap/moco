# UI/UX Layout Specification

## 1. Match Screen
- **Top**: Scoreboard (Team names, Scores, Sets)
- **Bottom-Right**: Skill Card Deck (Max 4 cards)
- **Bottom-Left**: Pause / Auto toggle / Speed toggle (1x, 2x)
- **Center**: 3D Match Field

## 2. Gacha Screen
- **Center**: Featured Character Art
- **Bottom**: "Pull 1" (300 Stones), "Pull 10" (3000 Stones)
- **Top-Right**: Remaining Stones (Paid/Free)

## 3. Team Management
- **Grid View**: List of owned characters with rarity icons.
- **Side Panel**: Detailed stats and equipped skills of selected character.
